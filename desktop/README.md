# 打字猫

用 Tauri 2、React、Vite 和 Three.js 构建的 Windows 桌面宠物应用，与上级目录共用核心场景与猫咪绘制逻辑。

## 使用

- 在打字猫窗口内按键，或直接点击画面中的键帽。按 **空格键** 时猫咪会甩尾敲击空格并触发小特效。
- 按 `Esc`（或右键系统托盘图标选择「设置」）打开/隐藏独立设置弹窗，支持调节：
  - **后台打字**：在其他窗口输入时实时响应物理按键，仅匹配模型支持的键位，不记录或保存输入文本。
  - **攒鱼与怒气**：默认开启，每 500 次按键攒 1 条鱼；怒气满 100% 切换为「罢工 · 想吃鱼」，拖鱼喂猫或开启听歌模式均可消气。
  - **听歌模式**：猫咪戴上头戴式耳机随旋律晃头、飘出音符并自动持续降低怒气值。
  - **装扮中心**：打开独立装扮弹窗，实时预览并切换 **6 款猫咪花色**（小黑猫、暹罗猫、狸花猫、布偶猫、大橘猫、三花猫）、**7 款猫瞳样式**、**6 款经典头戴式耳机** 与 **6 款键鼠联动配色**。
  - **大小与透明度**：窗口大小支持 `50%–120%`（默认 `65%`），整体透明度支持 `20%–100%`，均会自动记忆。
  - **检查更新与退出**：支持一键检查 GitHub 最新版本并下载安装包到下载目录；设置弹窗右上角电源图标支持二次确认退出。
- **窗口拖动与抚摸**：长按非头部区域（或 `Alt + 鼠标左键` 任意位置）可拖动窗口；长按/揉摸猫咪头部可触发抚摸（脸红、小爱心与喵叫），不会与拖动冲突。
- 闲置约 10 秒后，猫咪会横躺下来闭眼打盹并偶尔轻甩尾巴，打字、移鼠、点击或抚摸均可唤醒。
- 应用单实例运行。关闭主窗口会最小化到任务栏，右键系统托盘图标或点击设置弹窗电源图标可彻底退出。

## 开发与打包

从 `desktop` 目录执行以下命令。Windows 构建需要 MSVC C++ Build Tools 和 WebView2。

```powershell
npm ci
npm run tauri:dev
npm run release
```

`npm run release` 把免安装程序放到 `releases/v<版本>/typing-cat.exe`。例如当前版本是
`releases/v1.1.4/typing-cat.exe`。`src-tauri/target` 是构建目录。
`npm run release:installer` 还会把 Windows 安装包放进同一个版本目录。

把 `desktop/package.json` 的版本变更推送到 `main` 后，GitHub Actions 的 Release 工作流会构建并发布 Windows 免安装版和 NSIS 安装包。

应用图标原图在 `src-tauri/icons/icon-source.png`。更新原图后，用带 Pillow 的 Python 运行
`python scripts/build-icon.py` 生成 Windows 多尺寸 ICO 和 PNG。
